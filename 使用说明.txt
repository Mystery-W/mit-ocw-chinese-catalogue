MIT OCW 中文课程目录 — 2026-11-17 快照

开始使用
1. 双击“打开课程目录.html”。无需安装 Python，也无需启动服务器；目录搜索可离线使用。
2. 搜索中文或英文关键词、课程代码。多个空格分隔的关键词同时匹配。
3. 两个学科筛选同时生效，例如“音乐”与“计算机科学”。资源筛选与本科/研究生级别相互独立。
4. 点击课程标题或“简介与学习入口”，查看完整官方英文简介及所有课程导航链接。
5. 打开外部学习页面需要联网；“导出当前筛选结果 CSV”只导出当前筛选范围。

提供的文件
打开课程目录.html：完整内嵌数据的离线目录，可单独复制到另一台计算机。

课程总目录.csv：UTF-8 BOM，32 列，2587 行，保留完整简介。Excel 直接打开 CSV 可能把课程代码转为数字，建议使用 XLSX 来保留 1.00、1.010 等代码。
课程完整数据.json：结构化全文数据，含官方多级学科路径、资源导航链接、原始简介、出处和抓取时间。
validation.json / file_consistency_checks.json：覆盖检查、缺失字段检查和文件一致性检查。

可复现与刷新（完整工作目录内的脚本）
使用 Python 3.10+，依赖 requests 与 lxml。本次使用已有 CorpusCrawler 环境，未安装、升级或修改其依赖，未改动 base。
crawl_ocw.py：搜索接口与 sitemap 交叉发现、限速、重试、断点续抓、独立缓存、成功失败日志。
build_catalogue.py：按 URL 合并，整理翻译与资源分类，生成 JSON、CSV 和独立 HTML。
verify_entries.py：补充核查主要视频入口及标签缺失页面，仅检查页面响应，不下载媒体。
build_workbook.mjs：使用本次 Codex 捆绑 artifact-tool 库生成 XLSX。用于生成，不是阅读文件的必需依赖。

继续同一次抓取：在 PowerShell 中使用已有环境的 python 运行 crawl_ocw.py。
重新抓取未来快照：必须给 --output 一个新目录，避免复用旧快照缓存；不要以默认输出覆盖本次快照。
新快照可能有新课程或标题变化，需要补译并重新检查分类。已有 reviewed_resources.json 是本次核查结果，未来更新应重新核对，不能无条件沿用。
本次脚本和结果已在本机执行并检查；未进行另一台计算机的原生 Excel 应用测试。
